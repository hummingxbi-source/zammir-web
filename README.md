# ZAMMIR web

Demo del sitio de **Soluciones en Vidrio y Aluminio ZAMMIR** (Otumba, Estado de México).

- `index.html`: el sitio completo en un solo archivo (HTML, CSS y JavaScript sin dependencias de compilación).
- `img/`: fotos de trabajos reales en WebP, en dos tamaños (`-m` 860 px y `-g` 1600 px).

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta:

```
python -m http.server 8000
```

## Publicar

El sitio se publica con GitHub Pages desde la rama `main`, carpeta raíz.
